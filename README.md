# मित्र (Mitra) – आपका AI मित्र
Hindi/Hinglish AI assistant app for Android by **PlayRang Technologies** (package `com.playrang.rangstudio`, **v4.0** — store release for the PhonePe Indus Appstore; replaces the old Rang Studio video editor).

## Features
- **🎙️ Live बात (new in v3.0)** — ChatGPT-voice-style full-screen conversation with a big animated orb: just talk, Mitra answers in a natural voice, and you can interrupt it any time (barge-in). Uses the **Gemini Live API** (`gemini-3.8-live`, falling back to `gemini-3.1-flash-live-preview` / `gemini-2.5-flash-native-audio-preview-12-2025`) over a WebSocket with 16 kHz mic audio up and 24 kHz speech down, echo cancellation + noise suppression, live transcripts, Google Search grounding for current info, and **function calling** for phone tasks (call / WhatsApp / SMS by contact name, YouTube, open app, Google search, alarm, timer, maps, torch, camera, share, time). Needs the user's own free Gemini API key (Settings → AI इंजन; get one at aistudio.google.com). Without a key the same screen runs a fast turn-based loop (speech recognition → AI → speech → listens again). Mic mute + close buttons; choice of 5 Live voices.
- Saying **“मित्र”** (Always listen) opens Live mode when a Gemini key is set, otherwise the small voice screen.
- **Faster chat**: with a Gemini key replies stream (`streamGenerateContent`, SSE) and are spoken sentence by sentence while still being written; shorter timeouts on the free fallbacks.
- बोलकर (🎤, hi-IN speech recognition) या लिखकर कोई भी सवाल पूछें — जवाब चैट में दिखता है और हिंदी आवाज़ (TextToSpeech) में सुनाई देता है (🔊/🔇 toggle).
- AI: free Pollinations endpoint by default (≈1 reply / 45 s; the app shows a countdown and retries automatically). Optional Google Gemini API key in Settings for faster replies.
- Phone actions (local Hindi/Hinglish/English/Indian-language commands + AI `[[ACTION:...]]` tags + Live functions): कॉल, WhatsApp संदेश/कॉल, SMS, YouTube, कोई भी ऐप/वेबसाइट, Google search, अलार्म/टाइमर/रिमाइंडर, नक्शा/नेविगेशन, कैमरा/सेल्फ़ी, टॉर्च, आवाज़/साइलेंट, Wi-Fi/ब्लूटूथ/ब्राइटनेस सेटिंग, बैटरी, UPI ऐप, नोट कॉपी, हिसाब, शेयर, समय/तारीख — और एक वाक्य में कई काम।
- Fully native Android UI (no WebView, no remote website), pure Java, no extra libraries for Live (own tiny WebSocket client). No AccessibilityService; Mitra only opens apps with standard intents. No API key is stored in the code or repo.

## Changelog
- **v4.0 (25 Nov 2026, versionCode 7)** — store-ready release.
  - **Tasks**: many more on-device commands in Hindi / Hinglish / English / other Indian languages — volume up/down/mute/max, silent/vibrate, Wi-Fi / Bluetooth / brightness / location / flight mode / mobile data / hotspot / battery-saver / sound settings screens, battery level, reminders (calendar event, “कल सुबह 9 बजे याद दिलाना कि …”, “10 minute baad …”), notes copied to the clipboard, UPI apps (open only, never pays), selfie camera, turn-by-turn navigation, instant sums (“25 गुणा 4”, “200 का 15 प्रतिशत”). Any installed app opens by name with fuzzy matching on the launcher list (Hindi names, misspellings). **Multi-step**: “X को कॉल करो और फिर YouTube खोलो” runs in order (after a call it continues when you come back). AI tags and Live functions added for all of these.
  - **Languages**: auto-detects the script/language of every message (Hindi, Bhojpuri/Maithili in Devanagari → Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Punjabi, Kannada, Malayalam, Odia, Urdu, Nepali, English, Roman Hinglish) and tells the AI to reply in exactly that language; the recognizer listens in the last spoken language and TTS picks the voice from the reply (English replies use the en-IN voice). A language chosen in Settings overrides auto. Live system prompt follows the user's spoken language.
  - **Speed**: free AI engines now race in parallel (Pollinations + LLM7) instead of one after another; HTTP keep-alive (connections are no longer torn down) and a TLS pre-warm on app start; recognizer pre-created on start; voice screen replies stream sentence by sentence; YouTube lookup stops reading at the first video id; shorter fallback timeouts; local commands answer instantly with no AI round-trip.
  - **Listening**: partial text shown live, shorter end-of-speech silence, early stop when the partial text is already a complete command, Live VAD tuned (500 ms silence, high end-of-speech sensitivity) with AEC + noise suppression; wake word false-trigger guard (full-decoder agreement, near-silence reject, 4 s cool-down, temporary stricter threshold after two silent wake-ups).
  - **Fixes**: instant local answers were spoken while the beep-mute was still on (first words lost); concurrent AI requests could swap each other's language prompt (shared static); Live reconnect counter never reset; wake service could start without the mic permission (Android 14 crash); wake accepted when the full decoder heard nothing; wake “ack” beep removed; delayed actions ran after a screen was closed; YouTube could block a busy executor.
  - **Store**: removed `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` (setup opens the system battery list instead); every remaining permission justified in the privacy policy; Hindi explanation before the mic prompt; crash-safe first run with no key and no model.
- **v3.1** — Fix: the mic kept popping up with a repeated “tun-tun” beep. Always-listen now uses only the offline Vosk model (silent AudioRecord, no SpeechRecognizer loop; without the model it stays off and asks once to download it), the Google mic popup (RecognizerIntent) is never used, recognizer beeps are muted, empty listens back off (1 s → 3 s → stop), and wake word pauses with the screen off unless “स्क्रीन बंद पर भी सुनें” is on.

## Build
Every push to `main` runs `.github/workflows/build-apk.yml`, which builds a **signed release APK** (`Mitra.apk`) and publishes it as a GitHub Release tagged `mitra-v4.0-build-N`.
Signing uses repository secrets `KEYSTORE_B64` (base64 PKCS12) and `KEYSTORE_PASS` (alias `mitra`). The keystore is never committed — keep a safe backup; every future update must be signed with the same key.

> Users who have the old Rang Studio (v1, debug-signed) installed must uninstall it before installing Mitra, because the signing key changed.
